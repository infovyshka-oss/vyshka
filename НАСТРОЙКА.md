# vyshka.kz — запуск: хостинг, индексация и реклама

Короткое и важное: **реклама** и **выход в топ** — это РАЗНЫЕ вещи. Не путайте, иначе потеряете деньги или время.

| Что хотите | Чем достигается | Скорость | Стоимость |
|---|---|---|---|
| Сайт вообще появился в поиске | Индексация: Яндекс.Вебмастер + Google Search Console | дни–недели | бесплатно |
| Сайт **сразу наверху** по запросу | **Реклама**: Яндекс.Директ + Google Ads (оплата за клик) | сразу | платно, за каждый клик |
| Сайт наверху **бесплатно** | SEO + карточки на картах (2ГИС, Яндекс/Google Карты) | недели–месяцы | бесплатно/долго |

Реклама — это пометка «Реклама» над обычными результатами. Платите за клики. Выключили оплату — пропали из топа.
SEO/индексация — попадание в обычную выдачу. Бесплатно, но медленно и не гарантирует первое место.

Для нового сайта правильный порядок: **(1) выложить сайт → (2) подтвердить в Вебмастере и Search Console → (3) запустить рекламу для быстрых заявок → (4) параллельно растить SEO и карточки на картах.**

## ЧАСТЬ 1. Выложить сайт на GitHub Pages и привязать домен vyshka.kz

### 1.1. Создать репозиторий и залить файлы
1. Зарегистрируйтесь на https://github.com (если ещё нет).
2. Нажмите **New repository**, имя любое (например `vyshka`), тип **Public**, без README.
3. Залейте файлы сайта. Проще всего: на странице репозитория **Add file → Upload files**, перетащите ВСЁ содержимое этой папки (index.html, styles.css, script.js, картинки, favicon.svg, robots.txt, sitemap.xml, CNAME, 404.html, .nojekyll, папку assets) и нажмите **Commit changes**.
   - Либо через терминал (см. блок «Команды git» внизу).

### 1.2. Включить GitHub Pages
1. В репозитории: **Settings → Pages**.
2. **Source: Deploy from a branch**, ветка **main**, папка **/(root)** → **Save**.
3. Через 1–2 минуты появится временный адрес `https://ВАШ_ЛОГИН.github.io/vyshka/` — проверьте, что сайт открывается.

### 1.3. Привязать домен vyshka.kz
В файле `CNAME` (уже лежит в проекте) указан домен `vyshka.kz` — этого достаточно, чтобы GitHub знал ваш домен.

1. В **Settings → Pages → Custom domain** впишите `vyshka.kz` → **Save**.
2. Теперь нужно настроить DNS у регистратора, где купили домен. Где открыть редактор зоны:
   - **PS.KZ**: console.ps.kz → **Домены** → выбрать домен → **Управление DNS** (console.ps.kz/dns). Новая зона создаётся выключенной — после добавления записей её нужно **включить**. Домен должен использовать NS-серверы PS.KZ (ns1.ps.kz, ns2.ps.kz).
   - **hoster.kz**: вход в панель (Plesk) → вкладка **«Хостинг и DNS» → DNS**. Записи резолвятся только если у домена прописаны NS hoster.kz (ns1/ns2/ns3.hoster.kz).
   - Если панель регистратора не даёт добавлять A/CNAME — бесплатно подключите **Cloudflare** (cloudflare.com): добавьте домен, Cloudflare выдаст 2 своих NS-сервера, пропишите их у регистратора, а записи добавляйте уже в Cloudflare.

3. Добавьте записи:

   **Для домена без www (vyshka.kz) — четыре A-записи:**
   | Тип | Имя/Хост | Значение |
   |---|---|---|
   | A | @ (или пусто) | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |

   **Для www.vyshka.kz — одна CNAME-запись:**
   | Тип | Имя/Хост | Значение |
   |---|---|---|
   | CNAME | www | ВАШ_ЛОГИН.github.io |

   > ⚠️ Важно:
   > - Если у регистратора уже есть A-записи на «парковку»/заглушку — удалите их, оставьте только эти четыре.
   > - На **апекс-домене** (@) можно использовать только A-записи, НЕ CNAME. CNAME — только для www.
   > - (Опционально, IPv6) можно добавить 4 AAAA-записи на @: `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153` (A-записи при этом оставить).
   > - Если у домена есть **CAA-записи** — среди них должна быть разрешающая `letsencrypt.org`, иначе GitHub не выпустит HTTPS-сертификат.

4. Подождите от 15 минут до нескольких часов (иногда до суток) — DNS обновляется не мгновенно.
5. Вернитесь в **Settings → Pages** и поставьте галочку **Enforce HTTPS** (станет доступна после прохождения проверки DNS, иногда до 24 ч). Сертификат Let's Encrypt GitHub выпустит автоматически. Сайт будет работать по `https://vyshka.kz`.
   > Если Enforce HTTPS завис надолго — удалите домен в Settings → Pages и впишите заново, это перезапустит выпуск сертификата.

## ЧАСТЬ 2. Чтобы сайт появился в поиске (бесплатно, делать сразу)

### 2.1. Яндекс.Вебмастер
1. https://webmaster.yandex.ru → войдите, **Добавить сайт** → `https://vyshka.kz`.
2. Способ подтверждения **«Мета-тег»** — Яндекс даст строку с `yandex-verification`.
3. Откройте `index.html`, найдите блок «ПОДТВЕРЖДЕНИЕ ПРАВ» в `<head>`, раскомментируйте строку и вставьте свой код. Перезалейте файл на GitHub.
4. Нажмите **Проверить** в Вебмастере.
5. В Вебмастере: **Индексирование → Файлы Sitemap** → добавьте `https://vyshka.kz/sitemap.xml`.
6. **Переобход страниц** → добавьте `https://vyshka.kz/` для ускорения.

### 2.2. Google Search Console
1. https://search.google.com/search-console → **Добавить ресурс** → тип **«Ресурс с префиксом URL»** → `https://vyshka.kz/`.
2. Способ **«Тег HTML»** — Google даст `google-site-verification`. Так же раскомментируйте и вставьте в `<head>` index.html, перезалейте, нажмите **Подтвердить**.
3. **Файлы Sitemap** → добавьте `sitemap.xml`.
4. **Проверка URL** → введите `https://vyshka.kz/` → **Запросить индексирование**.

### 2.3. Аналитика (чтобы видеть посетителей и эффективность рекламы)
- **Яндекс.Метрика**: https://metrika.yandex.ru → создать счётчик → получите номер. В `index.html` раскомментируйте блок «Яндекс.Метрика», замените `XXXXXXXX` на номер счётчика.
- **Google Analytics 4**: https://analytics.google.com → создать ресурс → поток «Веб» → получите ID вида `G-XXXXXXXXXX`. Раскомментируйте блок «Google Analytics 4» и вставьте ID.

> Метрику/аналитику ставьте ДО запуска рекламы — иначе не увидите, окупается ли она.

## ЧАСТЬ 3. Реклама — быстрый выход наверх (платно)

> Оплата идёт **за клик** (аукцион в реальном времени). Это аренда места наверху: выключили бюджет — пропали из топа. Средний клик в РК — ориентировочно 30–1000 ₸, зависит от конкуренции. Перед запуском обязательно подключите Метрику/аналитику и настройте цели (звонок, отправка формы), иначе не поймёте, окупается ли реклама.

### 3.1. Google Ads (основной канал — в Казахстане поиск Google крупнее)
1. https://ads.google.com → страна **Казахстан**, валюта **тенге**, перейдите в **режим эксперта**.
2. Новая кампания, цель **«Лиды»**, тип **«Поисковая сеть»**.
3. Гео: город **Алматы**, в настройке местоположения выберите **«Присутствие: люди в указанном регионе»** (не «интерес + присутствие» — иначе платите за клики из других городов).
4. Ключевые фразы: `аренда автовышки алматы`, `заказать автовышку`, `автовышка в аренду`, `аренда агп алматы`, `автовышка 45 метров`.
5. Минус-слова: `работа`, `купить`, `вакансия`, `ремонт`, `своими руками`.
6. Объявление (адаптивное): до 15 заголовков и 4 описаний — «Выезд 24/7», «От 16 до 45 м», «По договору с НДС», телефон. Ссылка на `https://vyshka.kz`.
7. Стратегия — начните с **«Максимум кликов»**, после ~30 заявок переключитесь на **«Максимум конверсий»**.
   > Учтите: для компаний с НДС в РК нужно самостоятельно начислить и уплатить 12% НДС на рекламные расходы.

### 3.2. Яндекс.Директ (сильный второй канал — русскоязычная аудитория)
1. https://direct.yandex.kz → страна **Казахстан**, валюта **тенге**.
2. Кампания типа **«Поисковая»**, регион показа **Алматы**.
3. Ключи и минус-слова — как выше; объёмы подберите через **Яндекс Wordstat**.
4. Текст: «Выезд 24/7», «От 16 до 45 м», «По договору с НДС», телефон. Ссылка на `https://vyshka.kz`.
5. Задайте недельный бюджет; прогноз кликов/цены — через **Прогноз бюджета** (это оценка ±30%).

> Совет: ведите оба канала и сравнивайте **цену заявки**, а не цену клика. Бюджет на старте — небольшой, потом масштабируйте то, что окупается.

### 3.3. Карты и справочники (очень важно для «вызвать технику рядом»)
Бесплатно и часто эффективнее платной рекламы для локальных услуг:
- **2ГИС** — добавьте организацию (https://2gis.kz, раздел для бизнеса).
- **Яндекс Бизнес** (Яндекс.Карты) — https://business.yandex.ru.
- **Google Business Profile** (Google Карты) — https://business.google.com.

Заполните: название, телефон +7 707 912-22-55, сайт vyshka.kz, часы 24/7, фото техники, район/город. Это даёт показы на картах и помогает SEO.

## Что ещё стоит вписать вручную (для лучшего SEO)
В `index.html` в блоке микроразметки (`application/ld+json`) добавьте **реальный адрес** офиса/стоянки и координаты, например:
```json
"address": { "@type": "PostalAddress", "streetAddress": "ул. Пример, 1", "addressLocality": "Алматы", "postalCode": "050000", "addressCountry": "KZ" },
"geo": { "@type": "GeoCoordinates", "latitude": 43.2389, "longitude": 76.8897 }
```
Координаты можно скопировать из Яндекс/Google Карт (правый клик по точке → координаты).
